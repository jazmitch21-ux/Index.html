# North Star Bakery — Touchstone 3

This project uses a mobile-first CSS design system with cream, brown, peach, and charcoal colors; Georgia headings; Arial body text; Flexbox layouts; and a media query at 700px.

## Before submitting
1. Copy the provided bakery ZIP assets into the `assets/` folder using the exact filenames listed below:
   - bakery-logo.png
   - bakery-storefront.jpg
   - bakery-bread.jpg
   - bakery-signature-loaf.jpg
   - bakery-feature-small.jpg
   - bakery-feature-large.jpg
   - bakery-welcome.mp3
   - bakery-behind-scenes.mp4
2. Replace the placeholder location text and confirm the business hours and price ranges with the client scenario/instructor.
3. The contact form is front-end only (`action="#"`). Connect a form service if your course requires submissions to be delivered.
4. Upload the files to your public GitHub repository and paste the repository and preview links into the completed template. Enable GitHub Pages for a live preview if required.

Open `index.html` in a browser to preview locally.
